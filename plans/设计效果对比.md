## 🎬 动画效果对比

### 当前动画（简单翻转）
```
时间轴：0s ────────────────────────── 2s

动作：   旋转 ──────────────────────→ 停止
         ↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻↻

效果：   机械、单调、缺少物理感
```

### 优化后动画（物理模拟）
```
时间轴：0s ─────────────────────────────── 2.5s

阶段1：  抛起 (0-0.5s)
         ↑↑↑↑↑
         快速向上 + 开始旋转

阶段2：  空中翻转 (0.5-1.5s)
         ↻↻↻↻↻↻↻↻↻↻
         持续旋转 + 略微放大

阶段3：  下落 (1.5-2.1s)
         ↓↓↓↓↓
         加速下落 + 继续旋转

阶段4：  弹跳 (2.1-2.5s)
         ↑↓
         轻微弹跳 + 稳定

效果：   流畅、自然、有物理真实感
```

**动画参数：**
- 总时长：2.5秒
- 最高点：-180px
- 旋转圈数：4圈（1440度）
- 缓动函数：cubic-bezier(0.25, 0.46, 0.45, 0.94)
