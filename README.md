# 🐴 马年抛硬币

一个有趣的抛硬币小程序，带有特殊的概率事件！

## ✨ 特性

- 🎲 **正常结果**：正面或反面（各 47% 概率）
- 🎯 **硬币立住**：5% 的概率硬币会立住
- 💫 **硬币消失**：1% 的概率硬币会滚落下水道消失
- 🐴 **马年主题**：采用马年新年样式设计
- 🎨 **精美动画**：流畅的抛硬币动画效果

## 🛠️ 技术栈

- **React** - UI 框架
- **Next.js** - React 框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 样式框架

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 运行开发服务器

```bash
npm run dev
```

打开浏览器访问 [http://localhost:3000](http://localhost:3000)

### 构建生产版本

```bash
npm run build
npm start
```

## 📦 部署

项目配置为部署到 Vercel 平台，域名：linggxz.online

### Vercel 部署步骤

1. 将代码推送到 GitHub
2. 在 Vercel 中导入项目
3. 配置域名（Cloudflare DNS）
4. 自动部署

## 🎮 使用说明

1. 点击"抛硬币"按钮
2. 观看硬币旋转动画
3. 查看结果：
   - 🐴 正面 - 马到成功！
   - 福 反面 - 福星高照！
   - ✨ 立住 - 一马当先！
   - 💫 消失 - 硬币滚进下水道了...

## 📝 概率说明

- 正面：47%
- 反面：47%
- 立住：5%
- 消失：1%
